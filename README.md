## 📋 Descrição

O **Delivery SUS** é uma aplicação web desenvolvida para facilitar a solicitação, gerenciamento e acompanhamento da entrega domiciliar de medicamentos fornecidos pelo Sistema Único de Saúde (SUS) para pessoas com dificuldade de locomoção.

### 🎯 Público-Alvo
- Idosos (60+ anos)
- Pessoas com deficiência física
- Pessoas com mobilidade reduzida
- Pacientes em tratamento contínuo

### 🏥 UBS Atendidas
- UBS Pioneiras
- UBS Botafogo

---

## ✨ Funcionalidades

### Para Usuários
- ✅ Cadastro completo com validação de dados
- ✅ Login seguro com CPF e senha
- ✅ Solicitação de medicamentos disponíveis
- ✅ Consulta de disponibilidade em tempo real
- ✅ Acompanhamento de entregas
- ✅ Histórico de pedidos
- ✅ Confirmação de recebimento com código
- ✅ Notificações de status

### Para Administradores
- ✅ Gerenciamento de usuários
- ✅ Gerenciamento de medicamentos
- ✅ Controle de estoque por UBS
- ✅ Gerenciamento de entregadores
- ✅ Aprovação de solicitações
- ✅ Relatórios e estatísticas
